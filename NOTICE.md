# Splatoon Tools — Maintainer Notice

This is a maintained modernization by **Shadorux** of the original
[CoconutsXXS/Blender-Splatoon-Tool](https://github.com/CoconutsXXS/Blender-Splatoon-Tool).

The original project is approximately 3–4 years old and is no longer actively
maintained by its original author. This repository updates the Blender API
compatibility, packaging, importers, persistent customization UI, and related
fixes while preserving attribution to the original project.
